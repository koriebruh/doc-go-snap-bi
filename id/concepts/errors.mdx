SNAP mengenkode hasil sebuah response dengan dua cara sekaligus: status
HTTP level transport, dan `responseCode` 7 digit yang disematkan dalam JSON
body. Package ini memperlakukan keduanya sebagai **tidak sama-sama bisa
dipercaya**.

## Status HTTP adalah acuan utama

```go
func CheckResponseStatus(responseCode string, httpStatus int) error
```

`CheckResponseStatus` adalah pemeriksaan sukses/gagal tunggal dan otoritatif
yang dipakai setiap calling function. Status HTTP non-2xx **tidak pernah**
dianggap sukses, bahkan jika kelas status yang disematkan dalam
`responseCode` mengklaim sebaliknya — misalnya body cache basi dari
intermediary yang bermasalah, atau 500 di luar jalur dengan body
"success" bertemplat. Sebaliknya, status 2xx dengan `responseCode` yang
rusak atau hilang tetap dianggap sukses (tidak ada lagi yang bisa
diperiksa).

Mengembalikan `nil` untuk sukses, atau salah satu sentinel error di bawah.

## Struktur `responseCode`

```go
func ParseResponseCode(code string) (httpStatus int, serviceCode, caseCode string, err error)
```

Memecah `responseCode` SNAP 7 karakter menjadi `HTTPStatus(3)` +
`ServiceCode(2)` + `CaseCode(2)`. Mengembalikan error non-nil untuk apapun
yang bukan tepat 7 digit.

```go
func ResponseCodeError(code string) error
```

Mem-parsing `code` dan mengembalikan sentinel yang cocok dengan kelas
status HTTP-nya, di-wrap dengan `%w` di sekitar kode mentah sehingga Anda
bisa mengambilnya kembali sambil tetap mencocokkan kelasnya lewat
`errors.Is`. Kelas yang tidak dikenali mengembalikan `ErrUnmappedResponseCode`,
di-wrap dengan cara yang sama — tidak pernah `nil`.

## Sentinel error

Satu sentinel per kelas status HTTP yang didokumentasikan dalam tabel
response-code standar. Cocokkan dengan `errors.Is`, terlepas dari case
code spesifiknya:

| Sentinel | Kelas HTTP |
|---|---|
| `ErrBadRequest` | 400 |
| `ErrUnauthorized` | 401 |
| `ErrForbidden` | 403 |
| `ErrNotFound` | 404 |
| `ErrInternalServerError` | 500 |
| `ErrServiceUnavailable` | 503 |
| `ErrTimeout` | 504 |
| `ErrUnmappedResponseCode` | kelas lain/rusak |

```go
resp, err := balanceinfo.BalanceInquiry(ctx, transport, hb, req)
if err != nil {
	if errors.Is(err, snap.ErrUnauthorized) {
		// refresh access token lalu coba lagi
	}
	if errors.Is(err, snap.ErrTimeout) {
		// aman untuk retry hanya jika panggilan ini idempotent — lihat
		// catatan idempotency masing-masing endpoint di halaman referensinya
	}
}
```

## Input tidak tepercaya di pesan error

```go
func TruncateForError(s string) string
```

Membatasi string tidak tepercaya sebelum diinterpolasi ke pesan error,
sehingga input yang sangat besar tidak menghasilkan string error yang
proporsional besar (dan biasanya di-log). Diekspor agar jalur error
input-tidak-tepercaya milik domain subpackage sendiri (misalnya
`custIDMerchant` di `registration.CardRegistrationInquiry`) juga bisa
memakainya — gunakan ini jika Anda membangun error wrapping sendiri di
sekitar nilai yang berasal dari pemanggil.
