---

Istilah dari standar SNAP dan ekosistem pembayaran Indonesia, dipakai
secara konsisten di seluruh penamaan dan dokumentasi SDK ini.

| Istilah | Arti |
|---|---|
| **SNAP** | Standar Nasional Open API Pembayaran — standar nasional Bank Indonesia untuk open payment API, standar yang diimplementasikan package ini. |
| **ASPI** | Asosiasi Sistem Pembayaran Indonesia — asosiasi industri yang menerbitkan dan memelihara SNAP Developer Portal yang menjadi acuan endpoint binding package ini. |
| **PJP** | Penyedia Jasa Pembayaran — entitas bank, e-wallet, atau entitas teregulasi lain di salah satu sisi transaksi SNAP. |
| **Penyedia Layanan** | Sisi server dari sebuah integrasi SNAP — PJP yang menerima dan menjawab request. `ServerVerifier` dibangun untuk peran ini (lihat [Verifikasi request inbound](/id/concepts/webhooks)). |
| **Service Code** | Kode 2 digit yang mengidentifikasi satu endpoint SNAP spesifik dalam standar (mis. `11` untuk Balance Inquiry). [Tabel Status](/id/introduction) memetakan setiap domain package ke rentang Service Code-nya. |
| **responseCode** | Kode hasil 7 digit milik standar SNAP sendiri, disematkan di setiap response body: `HTTPStatus(3) + ServiceCode(2) + CaseCode(2)`. Lihat [`ParseResponseCode`](/id/concepts/errors). |
| **Envelope** | Bentuk response generik yang di-decode package ini (`snap.Envelope`): status HTTP level transport ditambah field envelope SNAP apapun yang dibawa body. Lihat [Transport](/id/concepts/transport). |
| **B2B** | Business-to-Business — grant access-token `client_credentials` yang mengidentifikasi integrasi itu sendiri, bukan satu customer akhir. Di-cache oleh [`TokenManager.AccessTokenB2B`](/id/concepts/authentication). |
| **B2B2C** | Business-to-Business-to-Consumer — grant `authorization_code`/`refresh_token` yang terikat pada satu customer akhir spesifik, didapat lewat flow bergaya OAuth (lihat [`GetOAuthURL`](/id/reference/registration)). Tidak pernah di-cache, karena setiap token milik satu customer. |
| **Symmetric / Asymmetric signing** | Dua mode signature SNAP yang disepakati dengan partner saat registrasi: symmetric (HMAC-SHA512, `ClientSecret` bersama) atau asymmetric (SHA256withRSA, keypair `crypto.Signer`). Lihat [Signing](/id/concepts/signing). |
| **Mandatory / Optional / Conditional** | Tiga kelas presensi field milik standar. Package ini merepresentasikannya lewat `omitempty` milik Go — lihat catatan di [Konvensi Inti](/id/concepts/conventions) tentang bagaimana Optional dan Conditional menyatu jadi satu tag `omitempty`. |
| **Idempotency / X-EXTERNAL-ID** | Sebagian besar endpoint tulis **tidak** idempotent — retry dengan `X-EXTERNAL-ID` baru berisiko menghasilkan transaksi duplikat, karena deteksi duplikat milik server sendiri berpatokan pada header tersebut. Setiap halaman referensi endpoint menyatakan ini secara eksplisit. |
| **Virtual Account (VA)** | Nomor akun sementara atau permanen yang diterbitkan PJP agar pembayar bisa membayar ke sana; lihat grup referensi [Virtual Account](/id/reference/transfer-credit/virtual-account). |
| **MPM / CPM** | Merchant-Presented Mode dan Customer-Presented Mode — dua flow pembayaran QRIS SNAP, dibedakan dari pihak mana yang menampilkan kode QR. Lihat [QR / MPM](/id/reference/transfer-credit/qr-mpm) (sisi kredit) dan [CPM](/id/reference/transfer-debit/cpm) (sisi debit). |
| **OTT** | One-Time Token — token berumur pendek yang diterbitkan [`ApplyOTT`](/id/reference/transfer-credit/qr-mpm) untuk mengotorisasi satu pembayaran QR MPM. |
| **RTGS / SKNBI / BI-FAST** | Tiga jalur settlement antarbank milik Bank Indonesia: Real-Time Gross Settlement (nilai tinggi, langsung), Sistem Kliring Nasional Bank Indonesia (kliring batch), dan BI-FAST (transfer ritel real-time). Masing-masing punya endpoint Trigger Transfer atau Direct Debit sendiri dan type notifikasi inbound-nya. |
| **`Money`** | Type nilai `{value, currency}` bersama milik package ini (`snap.Money`) — `value` adalah string desimal, tidak pernah float, untuk menghindari pembulatan floating-point biner pada nilai uang. Lihat [Konvensi Inti](/id/concepts/conventions). |
