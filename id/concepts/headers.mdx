`HeaderBuilder` menyusun header set wajib SNAP untuk sebuah transaction
request dan menandatanganinya dalam prosesnya — inilah satu-satunya type
yang dipakai setiap calling function.

## `HeaderBuilder`

```go
type HeaderBuilder struct {
	Method      string // metode HTTP, mis. "POST"
	EndpointURL string // full endpoint URL yang dipakai dalam signed string
	Body        []byte // bytes request body yang persis

	B2B2C                 bool   // apakah ini request B2B2C
	AccessToken           string // Authorization bearer token
	AuthorizationCustomer string // Authorization-Customer bearer token; wajib saat B2B2C true
	DeviceID              string // X-DEVICE-ID; wajib saat B2B2C true

	ClientKey  string
	PartnerID  string
	ExternalID string
	ChannelID  string

	Origin    string // opsional; header dihilangkan saat kosong
	IPAddress string
	Latitude  string
	Longitude string

	Profile Profile

	Symmetric    bool
	ClientSecret string        // dipakai saat Symmetric true
	Signer       crypto.Signer // dipakai saat Symmetric false
}
```

`Symmetric` memilih fungsi signing mana yang dipakai, mengikuti parameter
milik `BuildStringToSignTransaction` sendiri — isi tepat salah satu dari
`ClientSecret` (HMAC) atau `Signer` (RSA), sesuai kesepakatan integrasi Anda
dengan partner.

Calling function di setiap domain package men-set `Body` sendiri, dari
bytes persis hasil marshal typed request — Anda tidak perlu men-set-nya
sendiri untuk panggilan normal.

### `Build()`

```go
func (b HeaderBuilder) Build() (http.Header, error)
```

Menyusun `http.Header` untuk request, menandatanganinya lewat
`BuildStringToSignTransaction` dan `SignSymmetric`/`SignAsymmetric` sesuai
flag `Symmetric`. Biasanya Anda tidak perlu memanggil ini langsung —
`snap.Transport.Do` yang memanggilnya untuk Anda.

## `Profile` — hook kustomisasi per-PJP

Standar membiarkan dua hal terbuka untuk tiap PJP (Penyedia Jasa
Pembayaran): format timestamp dan konstruksi URL path. `Profile` adalah
interface yang dipanggil `HeaderBuilder` dan `TokenManager` untuk keduanya:

```go
type Profile interface {
	TimestampLayout() string
	BuildPath(serviceGroup, productType string) string
}
```

`DefaultProfile` mengimplementasikan perilaku standar persis:

```go
type DefaultProfile struct {
	Domain  string
	Version string
}
```

```go
func (p DefaultProfile) TimestampLayout() string
func (p DefaultProfile) BuildPath(serviceGroup, productType string) string
```

`TimestampLayout` mengembalikan `snap.DefaultTimestampLayout` (layout waktu
Go yang setara dengan format standar `yyyy-MM-ddTHH:mm:ss.SSSTZD`).
`BuildPath` mengembalikan `/{domain}/{version}/{service-group}/{product-type}`,
dengan `Version` default ke `"v1.0"` saat tidak diisi.

Penyimpangan spesifik bank diekspresikan sebagai struct kecil yang meng-embed
`DefaultProfile` dan meng-override satu method — bukan fork dari
`HeaderBuilder`.
