## Riwayat Transaksi

Pencarian list, detail, dan statement atas transaksi yang sudah settle — package `transactionhistory` (Service Codes 12-14).

<CodeGroup>
```go example.go
resp, err := transactionhistory.TransactionHistoryList(ctx, transport, hb, transactionhistory.TransactionHistoryListRequest{
	PartnerReferenceNo: "2020102900000000000001",
	FromDateTime: "2026-09-14T10:00:00+07:00",
	ToDateTime: "2026-09-14T10:00:00+07:00",
})
if err != nil {
	// errors.Is(err, snap.ErrBadRequest), snap.ErrUnauthorized, etc.
}
```
</CodeGroup>

### `TransactionHistoryList`

TransactionHistoryList memanggil endpoint SNAP Transaction History List (Service Code 12, path .../\{version\}/transaction-history-list). hb harus sudah membawa setiap field yang dibutuhkan snap.HeaderBuilder kecuali Body, yang diisi sendiri oleh TransactionHistoryList agar byte hasil marshal yang sama dipakai untuk signing maupun wire body.

```go
func TransactionHistoryList(ctx context.Context, t *snap.Transport, hb snap.HeaderBuilder, req TransactionHistoryListRequest) (TransactionHistoryListResponse, error)
```

**Request &mdash; `TransactionHistoryListRequest`**

TransactionHistoryListRequest adalah request body untuk API Transaction History List (Service Code 12).

PageSize dan PageNumber bertipe string, bukan int: Guides tab menandainya sebagai "Integer", tapi contoh kerja dari standar sendiri mengirimnya sebagai string JSON dalam tanda kutip (mis. "10") — ini memodelkan contoh wire yang sebenarnya.

### `BankStatement`

BankStatement memanggil endpoint SNAP API Bank Statement (Service Code 14, path .../\{version\}/bank-statement). hb harus sudah membawa setiap field yang dibutuhkan snap.HeaderBuilder kecuali Body, yang diisi sendiri oleh BankStatement agar byte hasil marshal yang sama dipakai untuk signing maupun wire body.

```go
func BankStatement(ctx context.Context, t *snap.Transport, hb snap.HeaderBuilder, req BankStatementRequest) (BankStatementResponse, error)
```

**Request &mdash; `BankStatementRequest`**

BankStatementRequest adalah request body untuk API Bank Statement (Service Code 14, grup Riwayat Transaksi).

BankCardToken dan AccountNo bersifat Kondisional dan saling eksklusif: menurut spesifikasi, BankCardToken wajib diisi jika AccountNo null, dan sebaliknya. Package ini hanya memvalidasi wire shape, tidak pernah aturan bisnis, jadi keduanya cuma ditandai omitempty; penegakan aturan XOR-nya diserahkan ke pemanggil.

|---|---|---|
