## Trigger Transfer

Panggilan inti pemindahan dana: intrabank, interbank, bulk, request-for-payment, RTGS, dan SKNBI — setiap jalur real-time-gross atau bulk punya tipe notifikasi masuk sendiri yang wajib diterima layanan Anda.

<CodeGroup>
```go example.go
resp, err := transfercredit.InterbankTransfer(ctx, transport, hb, transfercredit.InterbankTransferRequest{
	PartnerReferenceNo: "2020102900000000000001",
	Amount: snap.Money{Value: "500000.00", Currency: "IDR"},
	BeneficiaryAccountNo: "1234567890",
	BeneficiaryAccountName: "Jane Doe",
	BeneficiaryBankCode: "...",
	SourceAccountNo: "1234567890",
	TransactionDate: "2026-09-14T10:00:00+07:00",
})
if err != nil {
	// errors.Is(err, snap.ErrBadRequest), snap.ErrUnauthorized, etc.
}
```
</CodeGroup>

### `IntrabankTransfer`

IntrabankTransfer memanggil endpoint SNAP Intrabank Transfer (Service Code 17, path .../\{version\}/transfer-intrabank). hb harus sudah membawa setiap field yang dibutuhkan snap.HeaderBuilder kecuali Body, yang diisi sendiri oleh IntrabankTransfer agar byte hasil marshal yang persis sama dipakai untuk signing maupun wire body.

Operasi ini tidak idempotent dan package ini tidak melakukan retry. Pemanggil yang mengulang panggilan yang gagal atau timeout harus memakai X-EXTERNAL-ID yang sama, karena deteksi duplikat di sisi server berpatokan pada header itu — X-EXTERNAL-ID baru saat retry berisiko menghasilkan transfer ganda.

```go
func IntrabankTransfer(ctx context.Context, t *snap.Transport, hb snap.HeaderBuilder, req IntrabankTransferRequest) (IntrabankTransferResponse, error)
```

### `Notifikasi Interbank Bulk Transfer`

<Info>Hanya masuk (inbound) &mdash; package ini tidak memanggil endpoint untuk ini. Partner/switcher mengirim POST ke URL callback **Anda**; unmarshal body ke `InterbankBulkTransferNotificationRequest` setelah memverifikasinya dengan `snap.ServerVerifier` (lihat [Memverifikasi permintaan masuk](/id/concepts/webhooks)), lalu balas dengan bentuk di bawah.</Info>

**Diterima &mdash; `InterbankBulkTransferNotificationRequest`**

InterbankBulkTransferNotificationRequest adalah request body untuk API Interbank Bulk Transfer - Notification (Service Code 21, path .../\{version\}/transfer-interbank-bulk/notify). Ini adalah callback settlement yang diterima PJP, bukan panggilan yang dibuat package ini — tidak disediakan fungsi pemanggil. Pemanggil membuat HTTP handler sendiri untuk path ini, mengautentikasi panggilan masuk dengan ServerVerifier.VerifyTransactionRequest, lalu melakukan json.Unmarshal body ke tipe ini. BulkID, PartnerBulkID, dan BulkObject wajib menurut tab Guides.
